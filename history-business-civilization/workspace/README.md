# 历史里的商业文明

这是一个面向企业家、管理者、创业者与大众读者的历史叙事项目。项目用人物命运进入制度现场，在帝国、组织、财政与人性的交界处，观察商业文明如何形成，又如何失控。

## 当前版本

- 版本：MVP 0.1
- 建立日期：2026-07-18
- 主要成果：项目总纲、人物库、50个选题、首批10篇文章建议、内容生产SOP、AI协作方案、韩信长文样稿、12周发布排期、商业化方案、专题网站
- 史料原则：事实、解释、类比三层分开；优先核对正史与可靠整理本；争议处明示，不以演义补空白。

## 五条内容主线

1. 帝国创业史
2. 老板与将军
3. 谋士、顾问与中间人
4. 潜规则与血酬
5. 失败者列传

## 使用方式

从 `01_项目总纲` 确认边界，从 `04_选题库` 领取选题，在 `03_人物库` 与 `02_资料库` 完成事实卡，按 `05_文章大纲/文章结构模板.md` 写作，并以 `内容生产SOP.md` 完成审核、拆条与发布。
