# 编辑审核清单

## 一、故事是否成立

- [ ] 开头在500字内出现具体处境，而非抽象观点。
- [ ] 至少三个可核实的历史场景推动关系变化。
- [ ] 人物不是现代职位标签的替身。
- [ ] 每一节都在增加压力、改变关系或揭示代价。
- [ ] 删除“这个故事告诉我们”“值得每个老板学习”等说教句。

## 二、商业镜像是否克制

- [ ] 商业概念来自历史结构，而非强行贴标签。
- [ ] 同时呈现创始人、高管、基层或利益相关方至少两种视角。
- [ ] 不把复杂失败归结为性格缺陷。
- [ ] 现代场景不虚构可被误认成真实客户案例的细节。

## 三、史实与版权

- [ ] 已附史实核验卡。
- [ ] 所有逐字引文有来源并控制在合理长度。
- [ ] 课程启发只做观点转化，不复制原文和独特案例表达。
- [ ] 配图权利清晰；AI图标注为艺术创作。

## 四、语言与结尾

- [ ] 删除过密金句、网络热词和连续反问。
- [ ] 长短句有节奏，段落不过度碎片化。
- [ ] 标题有张力但不歪曲史实。
- [ ] 结尾回到物件、场景或人物动作，不列管理建议。

## 五、发布拆条

- [ ] 长文、音频、短视频和卡片共享同一事实底稿。
- [ ] 短内容没有截取到改变原意。
- [ ] 平台标题、封面、简介和来源说明已准备。
- [ ] 发布后要观察的指标与假设已记录。
